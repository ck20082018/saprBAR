# Синтетические файлы legacy

Файлы в этой папке созданы по таблицам `HELP_30B.MSG` и не являются файлами, полученными из оригинального SAPR-BAR.

- `cantilever.CN/.LD/.MD` — согласованный синтетический комплект в условно выбранной системе мм–кН–МПа;
- `broken-index.CN` — повреждённый вариант: стержень ссылается на отсутствующий узел 3;
- `unsupported-temperature.LD` — структурно корректный вариант с температурой `T`, которую расчётное ядро не поддерживает.

Успешная проверка этих файлов означает только соответствие нашему документированному текстовому профилю, а не подтверждённое чтение оригинальной программой.

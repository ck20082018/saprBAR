## Обновление

Собрать и проверить новую версию локально, передать только содержимое dist в новый каталог releases, проверить читаемость файлов пользователем caddy, затем атомарно переключить current. Не передавать macOS AppleDouble-файлы `._*`. Не перезаписывать существующие assets: новый выпуск получает отдельный каталог для отката.

## Откат к конфигурации CRM

```bash
sudo cp -a /etc/caddy/Caddyfile.before-saprbar-20261006 /etc/caddy/Caddyfile
sudo caddy validate --config /etc/caddy/Caddyfile --adapter caddyfile
sudo systemctl reload caddy
```

Откат восстанавливает прежние маршруты; для работающей CRM потребуется отдельно восстановить её upstream-сервисы, которые уже были недоступны до публикации SAPR-BAR. Пароли и ключи в документации не хранятся.

4.1. Общие параметры

 

В стандартном виде файл  MD  содержит три массива.

 

Массивы  РZ[1:10]  и  IZ[1:10]  содержат параметры задач 01-10, а массив  MS[1:NS2] - число промежуточных узлов ортонормирования  для  оболочечных элементов (CF2).

 

Общие для всех задач идентификаторы, размещенные в этих массивах, имеют следующий смысл:

  • IZ[1]=NР - число шагов интегрирования  на интервале  между узлами ортонормирования (стандартным значением является NP=1);
  • PZ[10]=Ireg - параметр управления точностью решения (Ireg = 0 - массив MS[1:NS2]  заполняется автоматически; Ireg = 1 - массив MS[1:NS2] заполняется пользователем). Стандартным значением является Ireg = 0. При этом значении гарантируется относительная погрешность решения соответствующей линейной или линеаризованной задачи, не превышающая  0.00001-0.000001; точность решения можно существенно повысить, увеличив значение параметра NP или число промежуточных узлов ортонормирования в массиве MS[1:NS2]  при Ireg = 1;
  • IZ[9]=Ind_r - методический параметр, учитывающий в задачах динамики инерцию вращения поперечных сечений оболочек и шпангоутов. (Ind_r=0, если инерция вращения учитывается; Ind_r=-1, если инерция вращения не учитывается);
  • IZ[10]=NZ - порядковый номер задачи (принимает значение от 01 до 10).

 

Примечания

  1. Максимальное число шагов интегрирования не должно превышать значения  NP=10.
  2. Максимальные значения числа узлов ортонормирования при заполнении массива MS[1:NS2] пользователем не должны более, чем четырехкратно, превышать их стандартные автоматические значения.

Параметрами задач  01,02  являются:

  • ε  (EPS) - относительная погрешность решения нелинейной задачи;
  • NL - максимальное число приближений  по методу  Ньютона (при NL = 0 решается линейная задача);
  • λ0 (lambda_0) - начальное значение параметра нагружения;
  • λk (lambda_k) - конечное значение параметра нагружения;
  • Δλ (d_lambda) - шаг по параметру нагружения;
  • Ind_n - методический параметр, равный 0, если в задаче 02 учитывается геометрическая нелинейность, и равный  -1, если в задаче 02 геометрическая нелинейность не учитывается.

 

Примечания

  1. Относительную погрешность решения геометрически или физически нелинейной задачи  e  можно задавать в пределах  10-3≤ε≤10-8. По умолчанию (при ε=0) относительная погрешность решения геометрически или физически нелинейной задачи задается равной:  e=10-6.
  2. Максимальное число приближений NL рекомендуется задавать в пределах 10≤NL≤30. Пользователь всегда может увеличить значение NL, если по протоколу решения задачи на экране дисплея или в файле RES увидит, что имеет место устойчивая тенденция к сходимости решения.
  3. Начальное значение параметра нагрузки  λ0  должно быть больше или равно 0. При λ0=0 автоматически задается значение  λ0=10-7  от базового значения нагрузки.
  4. Значения  λk<λ0  или Δλ≤0 вызывает состояние “Error”.

Параметрами задачи  03  являются:

  • εf  (EPS_f) - относительная погрешность определения коэффициентов Фурье;
  • ω (omega) - частота возбуждения;
  • nmax (n_max) - максимальная (по модулю) гармоника разложения внешних нагрузок в ряды Фурье по окружной координате  α2;
  • NA0 - параметр управления базовыми граничными условиями (WR0[*][*]).

 

Примечания

  1. При  εf =0  относительная погрешность определения коэффициентов Фурье по умолчанию принимается равной  εf=10-4.
  2. Значение  ω<0 вызывает состояние “Error”.

Параметрами задачи  05  являются:

  • ε  (EPS) - относительная погрешность решения геометрически нелинейной задачи  (см. п. 4.4.1);
  • NL≥0 - максимальное число приближений по методу Ньютона при решении задачи об определении предварительного НДС (см. п. 4.4.1); при NL = -1  решается задача о собственных колебаниях ненагруженной конструкции (нагрузки файла LD игнорируются);

  • Δω (d_omega) - шаг по параметру частоты;
  • M_0  - начальный тон колебаний;
  • M_k  - конечный тон колебаний;
  • NA1 - параметр управления модифицированными граничными условиями WR1[*][*].

 

Примечания: те же, что и к п. 4.4.3.

Параметрами задач  09,10  являются:

  • ε (EPS)- относительная погрешность решения геометрически и (или) физически нелинейной задачи (см. п. 4.4.1);
  • NL≥0 - максимальное число приближений по методу Ньютона при решении задачи об определении НДС (при NL = 0 решается линейная задача; см. п. 4.4.1);
  • N_1, N_2 - начальное и конечное число волн  в окружном направлении, определяющее диапазон волн, в котором разыскивается критическое значение параметра нагружения l;
  • λ0 (lambda_0) - начальное значение параметра нагружения;
  • λk (lambda_k) - конечное значение параметра нагружения;
  • Δλ (d_lambda) - шаг по параметру нагружения при отыскании его критического значения;
  • NA1 - параметр управления модифицированными граничными условиями WR1[*][*];
  • Ind_n - методический параметр, равный 0, если в задаче 10 учитывается геометрическая нелинейность, и равный -1, если в задаче 10 геометрическая нелинейность не учитывается (см. п. 4.4.1).

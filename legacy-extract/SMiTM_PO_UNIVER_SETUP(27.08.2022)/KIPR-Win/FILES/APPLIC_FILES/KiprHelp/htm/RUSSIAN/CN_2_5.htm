2.5. Оболочечные элементы (CF2)

 

Оболочечные элементы конструкции нумеруются в произвольном порядке.

 

CF2 описываются параметром  NS2 , а также массивами XR2[NS2][0:12] и HJ2[*][0:3].

 

Для P-го CF2 выбирается координатная поверхность, определяется направление координатной линий  α1 (рис.) и вводится P-я строка массива XR2:

  • N - число слоев в P-м CF2.

 

Рассматриваются  три  т и п а  координатных поверхностей оболочечных элементов:

Координаты  R0, RL  не должны выходить за габариты сечения эллипса.

2.5.4. Массив HJ2

 

Слои каждой оболочки нумеруются так, чтобы номера слоев в возрастали с увеличением локальной координаты  z (рис. 5).

 

 

Рис. 5

 

Обозначим через NP число слоев в оболочечном элементе с порядковым номером P, определяемое элементом XR2[P][12] массива XR2.

 

Тогда общее число слоев в конструкции LS вычисляется по формуле

 

LS=sum(NP).

 

Номерам слоев  j (j=1,…,NP)  ставятся в соответствие  номера внешних поверхностей этих слоев  j.  При этом номер 0 присваивается внутренней поверхности 1-го слоя. Суммарное число всех поверхностей слоев в конструкции вычисляется по формуле

 

MJ = LS + NS2 .

 

Предполагается, что толщина каждого из слоев изменяется по параболическому закону. Определяются базовые координаты

 

α10,    α1С=(α1L+α10)/2,    α1L

 

на образующей координатной поверхности P-го CF2.

 

Tогда тройка чисел

 

zj(α10),    zj (α1С),    zj (α1L)

 

определяет расстояние (с учетом знака)  j-й поверхности  (j=0,1,...,NP)  от координатной поверхности CF2.

 

Обозначим через  mj  порядковый номер строки в символьном массиве наименований материалов MAT[M][*], соответствующий материалу, из которого изготовлен j-й слой (j=1,...,NP).

 

Bводится  массив чисел  HJ2[MJ][0:3].  В первых  (N1+1) строках этого массива разместим величины

 

zj(α10),    zj (α1С),    zj (α1L),    mj

 

для  1-й оболочки;  в следующих (N2+1) строках - аналогичные величины для  2-й  оболочки и т.д.

 

Для поверхности оболочки с номером  j=0  необходимо задавать  mj=0.

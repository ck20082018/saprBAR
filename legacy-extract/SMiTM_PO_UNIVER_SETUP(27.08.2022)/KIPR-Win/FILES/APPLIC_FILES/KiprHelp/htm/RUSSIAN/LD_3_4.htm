3.4. Типы нагружения

 

Формирование массивов нагрузок, действующих на конструкцию, начинается с определения числа   т и п о в   внешних воздействий.

 

Число типов внешних воздействий определяется числом   р а з л и ч н ы х   функций F(α2)  распределения этих воздействий по окружной координате  α2. Для обозначения числа  т и п о в  воздействий вводится идентификатор NQN.

 

Пусть на конструкцию действуют нагрузки, задаваемые NQN  т и п а м и.  Тогда информация о  т и п а х  нагрузок задается с помощью массива NTAB[NQN][2],  в Nt-й строке которого в зависимости от функции F(α2) размещается один из следующих вариантов для  т и п а  нагружения с порядковым номером  Nt:

 

  • для закона 0:  0,  0;
  • для закона 1:  1,  N (N - число узлов на окружности, в которых заданы амплитуды функций Fi (i=0,1,…,N-1));
  • для закона 2:  2,  4×N (N – число дискретно расположенных участков с линейным распределением нагрузок на каждом участке);
  • для закона 3:  3,  2;
  • для закона 4:  4,  2;
  • для закона 5:  5,  2×N (N – число сосредоточенных сил).

 

Bводится идентификатор  LTA  для обозначения суммы элементов второго столбца массива  NTAB. Вводится также массив TAB[LTA]. Этот массив формируется по следующим правилам.

 

K текущим значениям этого массива последовательно добавляется:

 

  • для закона 0 - ничего;
  • для закона 1 - значения F1,...,FN;
  • для закона 2 - значения  α01,F01,α l1,Fl1;    α02,F02,αl2,Fl2;   и т.д.;
  • для закона 3 - n,Fn;
  • для закона 4 - n,Fn;
  • для закона 5 - α21,F1, ..., α2N, FN.
